## What this repository does **not** contain

No CHARLS data of any kind: not the raw waves, not the Harmonized extract,
and not the derived participant-level file `analysis_harmonized.csv`.

## Why not

The China Health and Retirement Longitudinal Study is distributed by the
Institute of Social Science Survey, Peking University. The CHARLS data-use
agreement prohibits redistribution of the data by registered users. The
Harmonized CHARLS documentation states the same constraint explicitly:

> "CHARLS license agreements do not allow us to disseminate the data directly."

We are bound by that agreement, so the data cannot be deposited here even
though it would make reproduction simpler. What we *can* deposit, and have
deposited, is the code plus every aggregate number it produces — so that
anyone who obtains CHARLS in their own right can regenerate our results
exactly.

## How to obtain the data

1. Register at <http://charls.pku.edu.cn> and accept the data-use agreement.
2. Download:
   - Harmonized CHARLS (Gateway to Global Aging Data, version D)
   - the 2011 blood-assay module (`Blood_20140429`)
3. Place them under `data/` in the layout that `scripts/clean_harmonized.py`
   expects (see README).

## Required attribution when you publish using CHARLS or Harmonized CHARLS

### Harmonized CHARLS (Gateway to Global Aging Data)

The Harmonized CHARLS Documentation (Version D, June 2021) asks all users to
include a specific acknowledgement in written work. The manuscript using this
repository carries it verbatim in its Acknowledgements section:

> "This analysis uses data or information from the Harmonized CHARLS dataset
> and Codebook, Version D as of June 2021 developed by the Gateway to Global
> Aging Data. The development of the Harmonized CHARLS was funded by the
> National Institute on Aging (R01 AG030153, RC2 AG036619, R03 AG043052).
> For more information, please refer to https://g2aging.org/."

The Gateway also asks that users **notify their team** of any written analysis
by e-mail to <papers@g2aging.org>. Anyone reusing this code with their own
Harmonized CHARLS extract should do the same for their own work.

Cite the dataset as:

- Phillips D, Green H, Petrosyan S, Shao K, Wilkens J, Lee J (2021).
  *Harmonized CHARLS Documentation, Version D (2011-2018)*. Gateway to Global
  Aging Data, University of Southern California. <https://g2aging.org/>

The CHARLS agreement requires that CHARLS be acknowledged and cited in any

Please follow the current CHARLS citation instructions on their website, as

## Reproducibility status of this repository

Verified 2026-11-03 by running the full pipeline from a clean checkout:

- `python scripts/run_all.py` completed all 12 steps with no warnings.
- **All 26 files in `_output/` were regenerated byte-for-byte identical** to
  the committed versions (`git status` clean afterwards).
- Figures 1–3 regenerate identically in content, dimensions and file size;
  the only byte-level difference is the PDF `/CreationDate` timestamp that
  matplotlib writes at render time.

## Ethical and regulatory notes

- CHARLS was approved by the Biomedical Ethics Review Committee of Peking
  University (IRB00001052-11015). This secondary analysis of de-identified
  data required no further approval.
- The aggregate files contain no individual-level or identifiable information.
- Every participant count in the aggregate outputs was audited on 2026-11-03.
  The smallest is **32** — the number of participants exposed to both
  metabolic syndrome and early incident stroke, which the manuscript also
  reports. All other participant counts are larger. Integers below 20 that
  appear in the JSON files are analysis metadata (bootstrap seeds,
  imputation indices, numbers of configuration cells, convergence-failure
  counters), not participants.
